COMMONLY USED NUMERICAL PERMISSIONS

777 = rwxrwxrwx
     → Owner, Group aur Others ko full permission.
     → Read + Write + Execute for everyone.
     → Generally avoid unless specifically required.

755 = rwxr-xr-x
     → Owner: Full access
     → Group: Read + Execute
     → Others: Read + Execute
     → Commonly used for executable files/directories.

700 = rwx------
     → Owner: Full access
     → Group: No access
     → Others: No access
     → Private files/directories ke liye useful.

644 = rw-r--r--
     → Owner: Read + Write
     → Group: Read only
     → Others: Read only
     → Normal files ke liye very commonly used.

600 = rw-------
     → Owner: Read + Write
     → Group: No access
     → Others: No access
     → Private/sensitive files ke liye useful.

444 = r--r--r--
     → Owner, Group aur Others: Read only
     → Kisi ko Write/Execute permission nahi

UMASK – IMPORTANT NOTES

umask = NEW file/folder ki default permissions ko BLOCK karta hai.

Check:
umask
Example: 0022

Pattern:
umask ABC
A = Owner
B = Group
C = Others

Values:
4 = Read block
2 = Write block
1 = Execute block
0 = Nothing block

Base Permission:
New File      = 666
New Directory = 777

Formula:
File      → 666 - umask
Directory → 777 - umask

Common:

umask 022
→ File      = 644 (rw-r--r--)
→ Directory = 755 (rwxr-xr-x)

umask 077
→ File      = 600 (rw-------)
→ Directory = 700 (rwx------)

umask 002
→ File      = 664 (rw-rw-r--)
→ Directory = 775 (rwxrwxr-x)

Remember:
chmod → Existing permission CHANGE
umask → New permission BLOCK
